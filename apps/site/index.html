What it is

Anchored to Bitcoin work

Every Bitcoin block moves S by a fixed function of its hash. Steering it means discarding blocks, and every discarded block costs its miner the block reward.

Anyone can recompute it

The rule fits in five lines. The chart above is rebuilt in your browser from public block hashes and checked against the contract.

No owner, no admin, no token

Nothing can pause, upgrade or redirect the contracts. There is no project token and nobody to trust with keys.

Runs unattended

Anyone may submit Bitcoin headers. If nobody does, the index waits; it never computes a wrong value.

How it works

For the raw 80-byte Bitcoin header at height h:

H = SHA256(SHA256(header))     // block hash
R = SHA256(H)                  // rehash
d = (sum of R's 32 bytes) − 4080
S = 1.2e−5 × Σ d               // from the anchor on
level = 100 × e^S

Each block moves S by about ±0.5% (one standard deviation), never more than ±4.9%. With no selective publication, the expected move is zero.

  1. Valid headers only

    The contract checks proof of work, difficulty retargets, timestamps and linkage exactly as Bitcoin does.

  2. 100 confirmations

    A height counts only once 100 valid blocks follow it, Bitcoin's own maturity for new coins.

  3. Deep reorganization seals

    If Bitcoin ever reorganizes past a counted height, anyone can prove it and the index freezes for good on its last consistent value.

Verify it yourself

Every Bitcoin header since height 11 has been replayed through the production contract and matched against an independent computation. Repeat it:

git clone https://github.com/MM-sheng/wuji && cd wuji
node scripts/replay-history.mjs                # needs a local header file
cd contracts && WUJI_REPLAY_DIR=cache/replay \
  forge test --match-contract FullHistoryReplay --gas-limit 18446744073709551615

Run a keeper

A keeper downloads Bitcoin headers straight from the Bitcoin network and submits them. It needs Node 18, Foundry and a small amount of ETH for gas. Keepers are paid from fees once the operations reserve holds any; anyone can run one, and the more independent keepers, the less WUJI depends on anybody.

A keeper also watches for deep Bitcoin reorganizations and seals the index by itself if one happens. Keep it running: it can only seal from states it has seen.
