## 0. 原则

1. **纯粹**：价格的唯一输入是链上区块哈希。没有预言机、没有治理、没有管理员、合约不可升级。
2. **自洽**：系统内每一块钱的盈利精确对应另一块钱的亏损；任何价格下金库都不能资不抵债。
3. **可验证**：任何人用公共 RPC 能从创世重算全部历史。索引层只是缓存，没有权威。

## 1. 指数（Index）

- 随机源：BSC 主网每个区块的 `blockhash`。
- 每块一个对数增量 `r_n = σ_block · Z_n`，`Z_n ~ N(0,1)` 由该块哈希确定：
  - `u1 = (hash[0..8]  as uint64) / 2^64`，取 `max(u1, 2^-53)`
  - `u2 = (hash[8..16] as uint64) / 2^64`
  - `Z = sqrt(-2·ln u1) · cos(2π·u2)`（Box-Muller）
- `σ_block = 1.4e-4`。BSC 目前 ≈0.45 s/块 ≈ 192k 块/天，对应日波动 ≈ 6%。
  - **已知取舍**：波动率跟随出块节奏。链变快市场就变"热"。接受——链是心跳。
- 累计 `S_n = Σ r_i`（从创世块起），指数价格 `P_n = 100 · exp(S_n)`。
- 创世块：`GENESIS_BLOCK = 122616000`（2026-09-18，BSC 主网）。原型阶段可重设；主网合约部署后永久固定。

## 2. 两仪（配对铸造）

- `mint(100 USDT) → 1 YANG + 1 YIN`（当期），`redeem(1 YANG + 1 YIN) → 100 USDT`，任何时刻。
- 价值：`YANG = 50 + 50 · (A_now − A_start)`，`YIN = 100 − YANG`。
  - `A` 是**算术**累计收益：每块 `A += (P_n / P_{n-1} − 1)`，即每块从输方向赢方转移 `50 · 涨跌幅`，**基数固定为 50**，不是各自余额。这是唯一让 YANG+YIN 恒等于 100 的转移规则。
- 边界：转移额不超过输方余额（截断到 0 / 100）。
- 封顶顺延：单日转移额上限 `50 × 15%`，超出部分记账到次日补，不凭空消失。
- **期次（Series）**：每期 30 天，从 50/50 起步，期末 `settle()` 按最终值兑现，下一期自动开。代币按期命名 `YANG-2610` / `YIN-2610`。
  - 为什么要期次：余额是转移额的累加，波动按 √T 增长（每日 σ≈3 块）。永远滚下去一年内触底概率约四成；30 天内约 0.5%。

## 3. 永续现货（滚动金库）

- `WUJI` = 持有当期 YANG 的金库份额；`YIN`（永续）= 持有当期 YIN 的镜像金库。
- 期末结算 → 两个金库**联合铸对**进下一期，差额走二级市场。
- 净值走法 ≠ 指数 `100·exp(S)`：每块涨跌幅 = `50·r / YANG`。接受，不用杠杆去追。前端两条都画：指数是"天气"，WUJI 净值是"你能买到的天气"。
- 标准 BEP-20，可上 DEX / CEX / 跨链。定义在链上，流通在任何地方。

## 4. 合约层

- **价格合约**：`tick()` 任何人可调，把上次记录以来的块哈希折进 `S`。Solidity 只能读最近 256 块（≈2 分钟），保障：
  1. 所有用户交易顺手 tick
  2. keeper 每分钟 tick，gas 由手续费池报销
  3. 断档（>256 块无人 tick）：断档增量**定义为 0**，链上留记录。丑但确定。
- **金库合约**：铸/赎/结算/期次代币。费率写死 0.05%，去向待定（keeper 池 / 烧 / LP）。
- 二级市场直接用 PancakeSwap：YANG/USDT、YIN/USDT，铸赎套利把两池价格之和钉在 100。`enterYANG(50 USDT)` 路由一笔交易铸对+卖 YIN。

## 5. 索引 / API（无权威缓存）

- 跟链读块，计算 `S`、`A`，落盘。
- `GET /head`、`GET /seconds?from&to`（每秒末价格）、`GET /candles?tf&from&to`、`GET /proof/:block`（哈希 → Z → r → S，可用任意 RPC 重算）。
- 客户端不可能自己从创世同步（一天 192k 块 ≈ 1GB RPC 流量），索引层从第一天就是必需的。
