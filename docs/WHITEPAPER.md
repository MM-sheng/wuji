可验证的随机结算指数与公开市场基准

## 1. 无极生太极，太极生两仪

WUJI 将公开比特币区块头映射为任何人可以重算的指数，再让独立应用使用它。这里的“无极”是预先固定的生成规则，“太极”是逐块形成的共同路径，“两仪”是围绕路径构造的两侧债权。它要提供的是一个不由项目方报价、不以外部资产行情为输入的公共参照：研究者可检验策略，开发者可定义结算产品，使用者可核对计算。当前配对金库只是一个示例应用；指数本身没有兑付义务。“纯随机”描述理想模型，不代表矿工无偏、与一切资产独立或持有必然获利已获证明。

## 2. 路径：从工作量证明到整数指数

对主链高度 h 的原始 80 字节区块头 B_h，定义：

```text
H_h = SHA256(SHA256(B_h))         // 原始 32 字节摘要
R_h = SHA256(H_h)                // 不对显示字符串再哈希
d_h = sum(R_h 的 32 个字节) - 4080
U_h = sum(d_j), j 从创世高度到 h
S_wad(h) = U_h × 12000000000000
S_h = S_wad(h) / 10^18;  I_h = 100 × exp(S_h)
```

浏览器常用的比特币哈希是 H_h 的字节反转。高度必须按链上顺序逐个计入，不能跳过缺失高度；只有其上已有指定数量后继头的高度才计入。当前 Sepolia header-v3 的 `WujiHeaderIndex` 自行验证提交的区块头，确认深度为 **100**，不使用 ZK 证明或独立 relay。历史 relay 版本的 `WujiIndex` 使用 **6** 个确认，不能仅凭“v3”名称混用参数。S_wad 是精确整数，I 仅供图表展示，不是可按该值赎回的代币。

**为何再哈希。** 有效 PoW 哈希的数值不大于难度目标，原始字节有受限高位。以真实高度 800000 的 `nBits=0x17053894` 为例，假设有效数值在区间内均匀，原始字节和均值约为 **2802.883**，直接减 4080 会产生偏差。再哈希在随机预言机模型下混合这些受限输入；它不能阻止矿工筛选结果。[计算与夹具](WHITEPAPER_FACTS.json)

**条件模型。** 若 R 的各字节及不同高度相互独立、均匀于 0…255，且无选择性发布，则 d 的均值为 0、方差为 `32×(256²−1)/12=174760`。S 单步标准差约 **0.50165%**，144 步标准差约 **6.01982%**；后者是按平均 144 块/天换算的对数指数尺度，不是实测日收益率。d 是有限支持的离散分布，不是截断正态。

**可复现**回答“怎么算”；**不可操纵、不可预测及独立性**各自需要额外假设和证据。尤其在区块公开后、链上折叠前，该增量已经可以被算出。

## 2a. 计入规则与输入边界

当前 header-only 指数的三个主要步骤如下；数据提交、支付 gas 和故障处置仍需要执行者：

1. **验证提交的连续区块头。** 哈希不大于目标、父链接、难度及 2016 块重定向（×4 / ÷4 上下限）、前 11 头中位时间和宿主链时间加 2 小时的上限均在合约内检查。这不是完整 Bitcoin 共识验证：不验证区块体、交易、UTXO 或脚本；当前合约也未检查该高度已激活的区块版本下限。
2. **只计入足够深的高度。** 从已终结状态重放一批头，末尾 100 个只作确认，前面的高度进入 S。这个深度不证明所提交路径是全球最重有效链，也不消除矿工选择性发布。不能把只基于算力比例的单一追赶模型直接当成 WUJI 的安全概率或资产规模上限。
3. **满足深重组证明后永久封存。** 分支必须从已承诺状态出发、不经过当前已终结链尾，累计工作量至少达到当前链工作量再加 `100 + 144` 个当前 tip 难度的块。单笔证据最多 800 头，分段接口每段最多 256 头；这不是可处理重组的最大深度。最终门槛随原链推进更新，不能把它换成固定墙钟时间或固定私挖块数。封存保留原 S 和检查点，不回滚已付资金；应用按自己的冻结规则继续处理。

提交无需许可，但诚实及时提交、网络可见性、部署锚点、宿主链与 RPC 都是剩余条件。无人提交时状态停留，合约不会自行追链或自动退款；有有效头不等于有全球选链证明。赏金来自可用运营储备，储备为零时提交可以成功但赏金为零。[当前验证范围](../verification/header-v3/PROTOCOL.md)

## 3. 两仪：有界债权，不同于指数本身

设一整对面值为 N 个抵押品最小单位，本期开期参考值为 S₀，预定结算高度为 T。用无量纲 S 定义名义分配函数：

```text
g(x) = min(1, max(0, 1/2 + x/2))
YANG 名义到期毛赔付 = N × g(S_T − S₀)
YIN  名义到期毛赔付 = N × [1 − g(S_T − S₀)]
```

两侧名义分配互补。合约用 wad 整数计算份额；`values()` 将 YIN 显示毛额定义为 N 减去 YANG 显示毛额，所以两者严格相加为 N。实际转账另按赎回数量、整数向下取整及费用计算；分别单边赎回可能留下舍入尘埃，不能把显示恒等式当作任意拆单后的净到账恒等式。[实现](../contracts/src/WujiVault.sol)

| 对象 | 它意味着什么 |
|---|---|
| 指数 S；展示 I | 公开输入对应的确定路径，不是金库承诺支付的价格。 |
| 即时结算份额 g | 当前状态下的分配比例；边界已记录后使用 S_T。 |
| 到期赔付 | 在固定 T 冻结后，持有人的合约权利，另扣费用与舍入。 |
| 市场价格 Q | 买卖双方实际成交的报价，受剩余分布、流动性和抵押品影响。 |

该规则取决于相对 S₀ 的**绝对位置**，不是每块复利或逐次搬移余额。例如 ΔS=0.2 时名义份额为 60% / 40%；即使此前碰过上界，只要未固定结算且 ΔS 回到 0.2，份额仍为 60% / 40%。在零利率、无摩擦且指定定价概率模型下，期内估值涉及未来赔付的条件期望，通常不等于当前 g。**g 和 `values()` 不得用作借贷抵押价格源。**

**持有人权利。** 铸造 q 对得到等量 YANG 与 YIN。未结算时，两侧各自可转让，但只有同一期、同数量的配对可以向金库赎回；单边不能按屏幕份额提前兑付。结算后可按冻结份额单边赎回。铸造抵押向上取整且另收 **5 bps（0.05%）**；配对或到期赎回按毛额收取 5 bps，转账按整数规则处理。Gas 与二级交易费用另计。

**随机性不产生现金流。** 理想模型的 `E[ΔS | 过去]=0` 不等于 `E[ΔI]=0`：指数映射是凸的，独立非退化增量下 `E[I_n]=I_0(E[exp(ΔS)])^n>I_0`。展示值的期望增长不是抵押池收入，也不是可兑现收益。用户所得来自抵押品、交易对手或市场买方，费用从中扣除。

“盈利就卖、亏损就等”属于交易策略，需要实际可执行的 Q 和流动性。指数触达目标不等于持仓兑现目标；定期债权也不授予原仓无限等待权。滚动策略必须单独定义再投资与净值，不能把各期重置曲线拼成同一资产的历史。[数学边界](WUJI_FOUNDATIONS.md)

## 3a. 永续账户：可变匹配、延迟定价与终止

配对债权按固定高度结算，不授予无限等待权。当前永续应用没有预定到期日，但也不保证账户永久存在或回到本金：零值可清退、池子可按规则永久终止，退出依赖未来高度与后续链上处理。

进场金额先扣费，余下为固定净本金 p。两侧以较小的本金总额匹配，较大一侧多出的部分按比例闲置。每个定价区间的匹配比例可变，因此实际累计盈亏由每侧累加器记录，不只取决于进场以来的 S 净变化。

```text
名义价值 = clamp(p + floor(p × (acc_结束 − acc_进场) / 10^27), 0, 2p)
```

`acc` 随各区间的 S 增量、方向、匹配比例和灵敏度 K 更新，整数取整以合约为准。`valueOf()` 使用已完成定价的累加器，不是最新 S 下的即时可提款报价。终止时还可能按资金比例折算；净到账另受费用与舍入影响。只有持续满匹配、忽略取整等额外假设下，才可把名义盈亏简化为 `p × 方向 × ΔS / K`。不能据此承诺“中位数永远等于本金”或任意异步账户盈亏严格互相抵消。

当前菜单的参数在部署后固定；标签是理想满匹配、平均出块模型下的目标尺度，不是账户的保证波动或触底概率。此处池子灵敏度 K 与指数的 100 个确认是不同参数。

| 档位标签 | 灵敏度 K |
|---|---:|
| 5% | 23 |
| 10% | 11.5 |
| 25% | 4.6 |

**资金与处理成本。** 每次定价扫描存续账户并检查名义负债是否有资金覆盖。待入场净本金 `pendingPrincipal`、退款准备金 `refundReserve`、已定价退出净款 `reservedClaims` 分开保留，不用于后来存续账户的亏损分担。每次调用最多处理 **64 个账户**，需要时由任何人继续；总成本随账户数量增长。处理中暂不接受新申请、清退或 sweep，已保留的旧领取款仍可支付。

**申请、定价、领取分开。** 当前 header-v3 池按指数验证过的最新头高度，加上按其时间戳年龄查表的余量，再向上取 6 的整数倍安排定价高度；最新头超过 24 小时不接受申请。余量来自含 2 小时时间戳偏差和 1.25 倍出块速率的条件模型，目标为选择尚未产生的高度，不是无条件不可预测证明。目标头出现后，仍需 100 个后继、指数折叠、历史价格认证和池处理。申请不可撤销；待入场尚无有效敞口，退出申请后则继续承受直到退出定价的变化。出块、停机和积压使等待时间不确定，不承诺几小时成交或随时足额提取。

**费用、归零与终止。** 进场按金额向上取整收 0.3%，正常退出按毛额向下取整收 0.3%；另有 gas。费用留作缓冲，支付处理/零值清退赏金并吸收实际净缺口。已定价退出费在定价时入账，领取先后不改变它。缓冲不足、可用资产仍低于存续名义负债时，池子自动永久终止：按同一快照的 `floor(名义价值 × 可用资产 / 总名义负债)` 分配；`badDebt` 记录名义差额，不由最后领取者单独承担。待入场净本金退还，已保留退出款照付；净本金退款不包含已经收取的入场费。未终止池中，零值账户可由任何人 `retire()` 清退，不保证等到指数回升后恢复。缓冲超过目标的部分可按规则转入费用路由；没有未结账户时可清理剩余资产。

**抵押品。** 当前示例为 WETH，本金与盈亏按其最小单位记账，不隔离 ETH 价格。可创建其他代币池不代表已审阅其兼容性；转账扣费、负向 rebase、冻结或实现变化可能破坏假设，不能把任意生息代币默认认定为同等安全。

**账户不是同质化代币。** 账户所有权可转让；若第三方报价、包装或借贷，它仍需评估实际债权和市场流动性。公开确定的 S 不会替代债权的价格发现。

**已验证与未验证。** 当前 Sepolia header-v3 真人 #3 阳 / #4 阴已完成进场、退出定价和领取，费用与回款有[逐笔记录](tasks/T13_WALLET_ROUNDTRIP_2026-10-22.md)；这不是任意规模偿付证明或独立安全审计。#5 后续处理、首次 type-4、独立运营及外部审阅仍各有未完成项。[当前合约](../contracts/src/WujiAccounts.sol) · [主网条件](MAINNET_CHECKLIST.md)

## 4. 抵押金库、工厂与运行经费

`WujiVaultFactory` 允许任何人为 `(抵押品地址, N)` 创建金库（金库目前绑定测试网 v3 的中继指数；是否接入 T13 指数尚待决定）；同一工厂内该组合唯一。金库绑定固定指数、代币部署器和费用去向，YANG/YIN 的铸造、销毁由其所属金库控制。工厂无资产白名单，**可创建不等于安全背书**。[工厂](../contracts/src/WujiVaultFactory.sol)

在余额报告真实、转账正确、无转账扣费或负向 rebase、无人能在协议外减少金库余额的普通 ERC-20 假设下，抵押余额覆盖未偿负债：开放期只增减配对；结算固定两侧份额后，销毁债权才释放对应抵押。`liabilities()` 汇总所有期次。该性质不保证美元购买力、发行人不冻结或抵押品实现永不变化。

不同链、抵押品、面值或期次构成**共享指数的一族独立债权**。资产身份至少包含 chainId、vault/token 地址、抵押品、N、seriesId 与方向；代币符号不能代替身份，也不存在由共同指数自动得到的跨链互换权。当前 Sepolia 使用已有 WETH，每对 **0.001 WETH**；BSC 使用 MockUSDT / MockWBNB。它们都是测试环境。[部署记录](../contracts/deployments/sepolia-weth-v3.json)

**费用服务于后续运行。** FeeRouter 将费用送往按币种分开的运营储备。每个首次成功折叠的高度，调用者对所选币种获得一次赏金 `floor(可用储备 / D)`；当前 header-v3 的 D = **100000**，部分旧 relay 部署为 **10000**，须按地址核对。已分配额度不再参与后来分配，没有销毁或永久积分，过去工作不分享未来收入。任何人可捐赠，但不产生权限。原子提交与折叠减少分开交易的抢赏窗口，不能保证竞争获胜。[储备](../contracts/src/RelayerRewards.sol)

这是有成本的系统。以每高度 **300000 gas** 的情景预算、**1 gwei** 和平均 **144 高度/天** 计算：约需 **0.0432 ETH/天**；下一高度赏金保本需约 **30 ETH 等值储备**（D = 100000；v3 的 D = 10000 时为 3 ETH），维持该成本需约 **86.4 ETH/天的费基交易量**。这不是实时报价或成本上限，也不含所有服务器、兑换和竞争成本。零收入且每高度均对该币种计赏时，储备近似 `R_h=R_0(1−1/D)^h`，忽略最小单位舍入约 **481 天**减半（v3 为 48.1 天）；非零储备不等于有人愿意运行。[情景计算](../scripts/keeper-economics.mjs)

当前成本应参考按版本和负载留存的收据，而非旧 gas 报价。2026-10-16 至 22 日七个不重叠窗口中，现有 keeper 共 34 笔交易、81,564,271 gas，支出 **0.0081564271 Sepolia ETH**；这是链上维护成本，不是七天完整稳定性验收。按相同日均工作量和 0.1 gwei 外推 30 天约 **0.03495612 Sepolia ETH**；最高单日工作量重复 30 天再加 25% 缓冲约 **0.05892102**。价格、负载或批量改变，结果就改变；宿主链报价、服务器/RPC 和独立审阅费用不能默认为零。[成本账本](tasks/T13_OPERATIONS_WEEK_2026-10-23.md) · [预算与补给](tasks/T13_MAINTENANCE_BUDGET_2026-10-23.md)

上述窗口 WETH 赏金分配和领取均为零；keeper 测试币补给是外部补贴，不是协议收入或经济自养。储备按比例衰减的半衰期也不是保证有人持续维护的期限。主网储备从零启动是既有选项，实际资助人、预算上限和停资后的服务安排仍需确定，不能用一次测试币转账替代。[启动决定（历史经济情景）](decisions/2026-10-02-submitter-economics.md)

## 5. 按高度结算，不按调用时点选结果

当前 header-v3 的创世高度 G 为 **969546**，检查点间隔 L 为 **4320**，边界为 `T_k=G+kL−1`（k≥1），首个边界 **973865**。固定验收样本尚未达到该高度，保持 NOT_REACHED。完整区间按平均出块速度约 30 天，不是日历截止承诺。历史 BSC/Sepolia relay-v3 的 G=967826、首边界 972145 不适用于当前候选。[参数与固定样本](../verification/header-v3/candidate.json)

检查点是指数记录，不是永续账户的到期日。历史配对金库的 `settle()` 另按其绑定指数和预定边界取 S_T，迟调用不能挑选更晚结果；不能将其 6 确认、续期或 50%/50% 规则套入当前永续池。后者按自己的未来定价队列处理。两者的后续调用均依赖外部执行者，并非合约自行唤醒。

## 6. 风险与失效边界

**矿工选择与公开信息。** 找到有效头的矿工可计算结果后选择发布或丢弃；攻击成本应按其私人成本衡量，包括矿池成本转嫁、短暂隐瞒、手续费及外部头寸，而非固定套用全网区块奖励。净单边敞口可能让筛选有利可图。已有简化成本模型不是已证明的安全 TVL 上限，当前也没有合约强制的敞口上限。区块公开到折叠之间存在已知结果交易窗口，K 个后继并不消除信息差。[威胁模型](THREAT_MODEL.md)

**SPV 与部署锚点。** 中继与 T13 指数都验证 PoW、父链接、难度调整、前 11 块中位时间及时间上限；中继另按累计工作量选链。部署时的检查点头、高度、难度周期起点时间与工作量基线仍需独立核对。它不验证所有交易、脚本和区块体，也不能从“见过的最高工作量”推出全球最高有效链。无报价管理员不等于无输入信任。

**时间门槛与停机。** 两种指数都拒绝超过宿主链时间 2 小时的头；中继版另在有积压时要求最佳头声称的时间不早于宿主链时间 3 小时。这只是时间戳门槛，不是全球同步证明。RPC、索引器或 keeper 失联会延迟计入与结算。权限开放不保证成本有人承担；浏览器直接读链也依赖其 RPC 回答。

**已折叠历史重组。** 当前 header-v3 使用 §2a 的工作量证明门槛永久封存，不撤销已折叠历史或已付资金。封存后，池中已经折叠的待处理定价高度须恢复并认证自身的历史价格；晚于封存高度的待入场净本金退款。封存前已开始的分批结算保留其价格，后续调用完成处理；缺头时等待，不能由先调用者任意选择冻结 S 替代历史价格。资金不足仍按 §3a 的固定比例终止规则处理。历史 relay-v4 的 `observeReorg()` / 144 高度等待 / 配对金库回退规则是另一版本，不能套用当前地址。上述路径有本地合成分叉与恢复记录，尚未经历真实深重组，亦无独立审计结论。[当前架构](ARCHITECTURE.md)

**抵押品与宿主链。** USDT 一类发行人资产可能冻结、列入黑名单或变更实现；WBNB、WETH 仍有封装合约和基础币价格风险。以它们计价的赔付不隔离美元价值波动。宿主链重组、审查、实现漏洞、前端内容替换和用户误认资产也会影响执行或体验。多链部署分开承担这些风险，不构成自动分散风险的证明。

**已有证据的范围。** 仓库历史夹具包含 2028 头、扩展的 **6060 个真实头与 4 个难度调整点**及 **345 组 Core 派生时间向量**；这不是本次重新执行的测试。当前 r4 固定样本是另一个范围：下载 4931 头、累加 2965 高度，作者保存的 Node 18/26 完整测试各 28 PASS。当前 v3 同机双来源比对与隔离恢复已有[记录](tasks/T13_DUAL_SOURCE_RECOVERY_2026-10-22.md)。金融不变量依赖普通代币和测试输入假设；这些材料均不证明矿工无偏、外部独立性或审计通过。

**仍未交付的条件。** 外部独立复算与用途反馈、对准确版本的独立安全审阅、第二运营者实际接手、首个自然检查点与完整周期、确定的持续维护承担，以及最终发布构建仍待完成；资金应用另须完成自己的审计、偿付与界面边界。现有同机双源/恢复不关闭这些条件。原生 ETH、CREATE2 等原定目标尚未实现；阶段发布不等于放行真实资金。[主网清单](MAINNET_CHECKLIST.md)

## 7. 不可越过的设计约束

不设置 owner、管理员、人工暂停、治理或升级密钥；不另发项目代币或治理代币。YANG/YIN 是有明确抵押与期次的应用债权，不是项目方发行的通用货币。规则与参数在部署时固定，错误通过另行部署及自愿迁移处理，不存在管理员替用户改账的入口。

协议不设置基金会控制角色，也不应依赖作者持续在线；这是一项需要通过“作者消失后仍可运行”演练检验的目标，而非关于法律实体或经济活性的证明。无管理权仍有代码、共识、输入、抵押品与运行成本假设。代码按 MIT 开放。

既有主网路线保留 header-only 指数、100 个确认、工作量深重组封存和运营储备，资金应用分阶段验收。当前执行重点是外部开发者独立复算与用途反馈，没有主网上线日期；历史选链建议不是当前 gas 报价或可承受成本结论。ZK 是历史研究路线，不是当前候选。原生 ETH、CREATE2 与 ENS 正本入口仍属未交付工程，不因文档更正而启动或放行。[当前任务入口](tasks/NEXT.md) · [主网清单](MAINNET_CHECKLIST.md)

## 8. 如何独立核对

在包含本文及配套工具的完整仓库中执行以下步骤；Node 工具不使用第三方运行库，签名账户不是读取验证的前提。

**一、核对当前候选。** 无钱包的 [r4 包](../verification/header-v3/README.md)固定 EVM 块 11969645、当前 header-v3 地址和参数，包含公开获取、离线重放、失败恢复与回传模板。基础测试 16 PASS / 12 SKIP；完整档案测试 28 PASS / 0 SKIP；缺数据不能把 SKIP 当 PASS。外部验收应由对方在其控制的环境获取，不使用作者缓存。示例命令中的新目录须此前不存在：

```bash
cd verification/header-v3
node verify.mjs integrity
node verify.test.mjs
node verify.mjs fetch ../wuji-v3-external-NEW
node verify.mjs replay ../wuji-v3-external-NEW
node verify.test.mjs ../wuji-v3-external-NEW
```

**二、区分历史算术与当前身份。** `scripts/whitepaper-facts.mjs` / `WHITEPAPER_FACTS.json` 保留旧 relay 部署参数和历史成本假设，不是当前 header-v3 的发布清单。其字节序向量仍可复算：高度 800000 的 R 为：

```text
74323d1b46bfc56d162ea5725ebc666028c5ee2b0a4824e32dedff53fe3ec1fd
```

该步 d 为 **−187**，对应 `ΔS_wad=−2244000000000000`。它同时有 JavaScript 和 Solidity 夹具测试；把显示哈希直接当输入会得出另一个结果。

```bash
node scripts/whitepaper-facts.mjs
node --test indexer/bitcoin.test.mjs
forge test --root contracts
```

**历史 relay 工具。** 下列 `wuji-verify` 和字节码脚本面向各自指定的旧部署，不能用它们替代当前 r4 的候选校验；两个域名也不证明运营者独立。历史命令保留用于复现：

```bash
node scripts/wuji-verify.mjs \
  contracts/deployments/sepolia-weth-v3.json
bash scripts/verify-bytecode.sh \
  contracts/deployments/sepolia-weth-v3.json
```

当前部署清单是 `contracts/deployments/sepolia-header-v3.json`，不是旧 `sepolia-t13.json`。r4 核对固定块运行代码指纹、参数与历史重放，但不承担源码编译到链上字节码的复证或安全审计。源码审阅须另按[当前审阅入口](tasks/REVIEW_HANDOFF_2026-10-22.md)固定版本和范围；不能把历史编译成功扩写为当前独立审计通过。

**三、核对所见与所持。** 终端支持自选索引器、独立配置 RPC 和同一 EVM 区块的 S/份额逐位比较；过期、失败、仅直读与匹配分别显示。交易前核对链、金库、抵押品、面值和期次。IPFS CID 标识页面内容，不自动提供可信 RPC 或永久托管。[独立运行与 IPFS](TERMINAL_IPFS.md)

## 9. 公开基准：先登记问题，再看结果

WUJI 的研究价值在于公开输入、固定算法和可重放历史，让“偶然走出好看的曲线”有可检查的对照。它可以支持策略检验、界面与结算实验，以及外部资产依赖性研究；这些是可检验用途，不是已经建立的收益或避险优势。

一项研究至少应在看测试样本前公开不可回改的登记记录，包含：

1. **样本与对象：** 起止高度、创世/规则版本、开发集与样本外分割点、固定计价单位、按块或按自然时间的采样频率；明确研究 S、I、某期赔付，还是可执行 Q。
2. **信息与策略：** 零假设、策略及参数、全部尝试的数量、开平仓与等待上限、资本约束，以及区块何时公开、何时可被本策略观察。不得把尚未观察到的最终历史倒填成当时可交易的信息。
3. **执行与成本：** 成交来源、点差、滑点、gas、协议费和资金占用；没有真实成交数据时标为模拟，不能把 `values()` 当成交价。相关性研究要分开控制抵押品回报与自然时间出块速度。
4. **评价与失败：** 报告全部试验，预先指定多重检验校正；同时列出已实现与未实现损益、等待时间分布、最大回撤、未退出/破产/断源样本，使用样本外结果评价。

只统计“已经止盈的单”会系统性漏掉还在等待的损失；相关系数接近零也不证明联合独立。连续图表记录指数，各期债权与策略 NAV 分别记录。当前交付的是此登记规范，**尚未公布一项按该规范预注册并完成的有效性实验**。[研究定义 §§9–10](WUJI_FOUNDATIONS.md)

## 10. 相关工作与贡献边界

**Bitcoin Beacon。** Bentov、Gabizon 与 Zuckerman（2016）研究在明确对手假设下构造公开可验证随机性。WUJI 逐头再哈希不等于该论文协议，不能继承其安全结论。[原论文](https://arxiv.org/abs/1605.04559)

**Gnosis Conditional Tokens。** 其抵押拆分、条件份额与合并机制是已有先例。WUJI 的配对拆分并非新概念；这里采用固定的指数路径与有界高度结算规则。[官方机制说明](https://ct-docs.gnosis.io/conditionaltokens/docs/devguide05)

**Deriv Synthetic Indices。** Deriv 已提供由密码学随机数生成器驱动的模拟市场。WUJI 的工程方向是让输入可由公开区块头重算、结算规则可由公开合约执行，不声称首次发明随机市场，也不把对方的随机性宣传当作自身安全证据。[官方产品资料](https://deriv.com/markets/derived-indices/synthetic-indices)

WUJI 的可检验贡献是把公开路径、无管理密钥的有界结算、按工作付费及独立运行工具接在一起。它是否形成有价值的公共设施，取决于能否被他人独立核对、持续运行并实际使用；这一点需要数据和运行记录回答。
