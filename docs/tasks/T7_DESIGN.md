# T7 · 滚动持仓设计：净值、执行条件与是否值得构建

2026-09-21 · 协议基线 `5a3b745` · 状态：设计与离线复算已交付，待评审；没有滚动合约或新代币。

## 1. 结论与范围

**当前建议：不构建或发行“永续 WUJI”滚动代币。** 将滚动保留为独立应用研究；以后有真实报价、
对手资金与明确退出规则时，可评估用户自行选择的换期工具。公共指数、中继与配对结算不需要滚动应用才能成立。

这不是否定其他人使用指数构建产品，而是确定本轮交付边界：正确的价值换算能避免凭空增减资产，
但不会把一个没有交易优势的公平随机敞口变成时间收益。当前也没有证据支持自动滚动能永久保持原仓的权利。

T7 原任务将“1:1 换期”与因子 `2g(X)` 写在一起，需要分开：前者是错误的数量换算；后者恰恰是
**按价值正确换期、全部购买同方向且新期价为 N/2 时**的财富因子。修正前者不会消除后者的风险。

## 2. 权利与资金来源先于净值曲线

设期次 k 的参考值为 S₀,k，预定边界为 Tₖ；Xₖ=S(Tₖ)−S₀,k。
定义 Aₖ⁺=g(Xₖ)、Aₖ⁻=1−g(Xₖ)，其中 g(x)=clamp(½+x/2,0,1)。
N 是每整对的抵押品面值。一枚旧期代币只享有该期冻结赔付，不会自然变成一枚新期代币。

设 Wₖ 为进入第 k 期前的现金，qₖ 为实际买入数量，Qₖ 为每枚真实买入价格，Cₖ 为买入后剩余现金。
忽略整数舍入的通用自融资账本为：

```text
q_k * Q_k + entry_cost_k + C_k = W_k
W_(k+1) = C_k + q_k * N * A_k * (1 - redeem_fee) - later_cost_k
```

0.8N 的旧期毛赔付只有在 **Qₖ₊₁=0.5N 且无费用**时能买 1.6 枚；若 Q=0.6N，则只能买 4/3 枚。
真正可投资的是到账净额。没有卖方或可接受报价时，q=0、现金等待；不能把 `yangShare()` 或 `values()` 当买入价格。

单边买入不能靠单边 mint 完成。现有 `mint` 总是铸造同数量的两侧。例：原来一对赔付 80/20，
两位持有人分别想以每枚 50 元全部换期，需求为 1.6 YANG 与 0.4 YIN。仅两人配对最多满足 0.4 对，
YANG 买方剩余 60 元必须等待或找到额外 YIN 买方/库存提供者。不能通过重标记余额补齐。
因此模拟中的充分流动性是外部假设，不是金库提供的权利。

实际可变现净值应为“现金 + 所有代币按可执行卖价计价 − 退出成本”。没有买价、卖价或深度时，
只能报告数量、期次、现金和估值缺失。多个抵押品分别记账，不用未经说明的美元价格或混合面值抵消风险。

## 3. 为什么正确换期仍有几何损耗

以下是**条件数学模型**：整期 X 对称、各期独立，进入时没有已知未来增量，Q=N/2，无费用、
无利息且始终有足额对手方。它不声称真实链上交易满足这些条件。

令 Y=2g(X)−1=clamp(X,−1,1)，则 E[Y]=0。全额同方向滚动的财富因子为：

```text
G_YANG = 2g(X) = 1 + Y
G_YIN  = 2[1-g(X)] = 1 - Y
W_n = W_0 * product(G_k)
E[G] = 1
```

对非退化正因子，严格凹性给出 E[log G] < log E[G] = 0；若 P(G=0)>0，则扩展意义下
E[log G]=−∞，不是一个可忽略的有限负数。理想独立均匀字节模型在 4320 步内允许 X≤−1 或 X≥1，
所以单侧零赔付事件有正概率。这不等于已测得真实矿工下的概率。
关于所用不等式，见 [MIT Jensen 讲义](https://live.ocw.mit.edu/courses/res-6-012-introduction-to-probability-spring-2018/b2f8d5b2c090f1c26d851247a47305be_GDJFLfmyb20.pdf)；
把它用于这里的赔付因子，是本文基于上述假设的推导。

在该独立模型中，若每期破产概率为 p>0，经历 n 期仍未遇到零因子的概率是 (1−p)ⁿ。
有限期 E[Wₙ]=W₀ 可以与最终破产概率趋近 1 同时成立；少数大额结果支撑算术期望，不能用来保证个人路径。
这也不是“每一期必亏”，更不意味着某次历史盈利无效。

一个无需概率的例子：X₁=+0.6、X₂=−0.6，正确再投资得到 `1.6×0.4=0.64`，本金剩 64%。
指数两期 ΔS 相加为零，却不意味着滚动策略回本。换期改变了参考值和持有数量；亏损期已经实现，
下一期的回升不再是原仓同一赔付函数的回升。

只拿比例 α 的现金做单侧敞口，其余无息保留，在相同理想模型下：

```text
G_alpha = 1 + alpha * Y      // YIN 使用 -Y
0 < alpha < 1  => G_alpha >= 1-alpha > 0
E[log G_alpha] < 0           // 非退化、无交易优势
```

α=25% 能让单期方向性零赔付后还剩 75% 现金，但不会产生正的期望对数增长；固定费用、
托管和长期反复损失仍在。两侧等量持有的毛赔付恒为面值，扣费后也不会凭空产生收益。
若存在可验证的定价优势，必须针对实际 Q、可见信息和成本单独研究；它不来自“随机”二字本身。

## 4. 50/50 不是可以按时获得的报价

旧期 T 获得 6 个后继后才能结算。这时新期的 T+1…T+6 已经公开，即使它们尚未折叠。
迟调用时已知的范围还可能更长。新期的 S₀ 仍是 S(T)，不会因迟调用而重新选择基准。

用指定概率模型表示估值时，应对交易者实际可见信息 Fₜ 条件化：

```text
p_model = E[A_(k+1) | F_t]
```

这仍是模型估值而非成交承诺，也未计入费用、流动性、重组及抵押品风险。已知增量通常会使模型值偏离 ½。
不能一边使用 6 个后继保障结算，一边假设买卖双方都不知道它们。也不能把全部最终历史提前喂给策略。

历史样本的第一个 4320 高度边界是 802655；随后 6 块的已知 ΔS 为 **+0.005436**。
它是直接可算的信息，不是估计的未来走势，也不是“新期价格=0.502718N”的依据：剩余期分布与截断仍须考虑。

  `2ca6fc01b2c75511c6829b606028e0a78a32cb345dc7c7a517ba6ff0ff66ea09`。

- 历史假设创世点为 **798336**，不是当前部署的 967826；面值沿用 Sepolia 的 0.001 WETH。

- 从第一头起按时间顺序、非重叠分段，不挑选起点，不重采样，不把重叠窗口称为独立实验。
  4320 是生产间隔；1008 和 144 仅为较短期压力对照，不修改部署参数。
- 两个方向 × 100%/25% 配置 × 三种费用 × 三种间隔，共 **36 组全部报告**。
  第一档去掉所有费用；第二档只计真实的 5 bps 赎回费；第三档另加假设的 10 bps 买入附加成本
  和每次入场预付 0.0003 WETH 的整轮固定成本。这是情景金额，不是 gas 实测或上限。
  二级买入不会自动收取 `WujiVault.mint` 的 5 bps，因此没有给每笔二级买入虚构铸造费。
- **所有入场价都假设 N/2 且无限深度。** 这故意保留了理想价格，尤其没有解决上一节的已知信息问题。
  结果只说明在这个假设下的现金账本，不能称为可成交回测、真实收益记录或定价优势证据。

## 6. 整数账本与未来应用的最低条件

模拟的买入预算 b=floor((现金−固定成本)×α)；Q 为每整枚报价，q 使用 18 位数量。
买入成本 `ceil(q×Q/WAD)`，假设附加费另向上取整；寻找满足预算的最大 q，余款继续记为现金。
结算严格按当前单边实现计算：

```text
gross = floor(q * N * A_wad / WAD^2)
fee   = floor(gross * 5 / 10000)
cash_after = cash_idle + gross - fee
```

不把 `values()` 的互补显示规则替代实际转账舍入。配置的零费档仅用于比较；不是可在生产合约中选择的开关。
无报价或预算不足时不发起交易，现金不变；已发送但失败的交易仍可能消耗 gas，当前历史样本没有这些执行记录。

若评审后决定做换期工具，优先评估每用户持仓的有限路由，不先发行需要统一 NAV 的池化份额：

1. **输入与授权：** 用户固定链、vault、抵押品、面值、旧/新 series、方向、最大支出、最少收到数量和期限；
   不授权后台任意选方向、改面值或挪用其他期次。权限开放不等于接受任意报价。
2. **结算与报价：** 旧期已结算才赎回；新期必须可 mint/交易且未过边界。按实际可接受报价和深度换入，
   不能内置管理员定价、`g` 定价或强制 50/50。撮合两侧或使用外部库存时，都验证足额抵押和成交上限。
3. **失败与退出：** 无报价就等待现金；赎回后买入失败不得丢失现金。原子交易全回滚或明确的独立阶段，
   必须择一写入规格。用户始终可取回其现金/原始代币；“取回未结算代币”不等于能单边兑付抵押品。
4. **故障边界：** 深重组、停机、发行人冻结和旧债权无法结算不会被 wrapper 修复。T9 的退出规则要先独立解决。
   不借新用户存款填旧期损失、不承诺保本、不把失败队列伪装成持续敞口。
5. **份额与可视化：** 无真实估值时不按 `values()` 接受池化存取款；否则新老用户可互相稀释或套利。
   显示独立的 S 历史、各期债权和策略账本。不同资产或期次不拼成同一现货价格。

以上是供评审的接口与失败条件，不是已经批准、实现或审计的合约规格。固定比例留现金也只是风险配置，
不作为默认投资建议。指数层不会因此增加管理者、额外代币、可变费率或升级权限。
