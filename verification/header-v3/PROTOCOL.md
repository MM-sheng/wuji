# 当前协议说明：Sepolia header-v3

本页只描述候选 `wuji-sepolia-header-v3-fixed-11969645`。旧 relay、旧两仪金库和 ZK 研究版本的参数不适用于本包。当前协议身份和固定历史样本以 `candidate.json` 为机器可读入口。

## 1. 它提供什么

WUJI 将一段公开 Bitcoin 区块头路径映射为整数结算指数 `S`，供其他程序用同一规则复算。合约没有 owner、管理员、暂停开关、升级、治理或项目代币。有人仍需提供数据、支付宿主链费用并持续提交；无管理特权不等于自动在线。

指数本身不是资产、收益权或可成交报价。外部应用若把 S 变成资金权利，须另行说明资本来源、进出场规则、费用和故障处理。本包仅支持历史复算与无资金消费者。

## 3. 指数的精确定义

每个高度 h 从 969546 开始：

```text
header = Bitcoin serialized 80-byte block header
H      = SHA256(SHA256(header))       // raw 32 bytes
R      = SHA256(H)                   // raw bytes, not display hex or ASCII
delta  = sum(R[0..31]) - 4080
U_h    = U_(h-1) + delta             // U_969545 = 0
S_wad  = U_h * 12000000000000
S      = S_wad / 10^18
I      = 100 * exp(S)                // display only
```

头格式为：4 字节 version、32 字节 previous hash、32 字节 merkle root、4 字节 time、4 字节 nBits、4 字节 nonce；数值字段小端序。Bitcoin 浏览器显示哈希是 H 的字节反序。`vector.json` 给出主网高度 800000 的完整编码向量：`delta=-187`，`deltaS_wad=-2244000000000000`。它用于验证编码，不属于本部署的累加范围。

所有比较使用整数，不能通过比较 `100*exp(S)` 的舍入结果验收。在 32 字节独立均匀、各块独立的理想模型中，delta 均值为零，方差为 174760；这不是实际矿工无偏、任意资产独立或用户获利的证明。

## 4. 区块头如何成为链上 S

当前合约从已经记录的 finalized tip 出发，重放提交的连续头，验证链接、PoW、难度及 2016 块 retarget、前 11 头 MTP、相对宿主链时间最多提前 2 小时。最后 100 个头只作确认；S 和 finalized continuity 停在其前面。`seenHeight`/`seenTime` 记录曾验证到的较高头，不计入 S。

它不在合约里维护并比较所有分支以证明全球最重链，也不验证交易、区块体、UTXO 或脚本。诚实及时的提交、网络可见性、锚点和宿主链/RPC 仍是条件。100 个确认不能消除矿工对已找到区块的选择偏置。

若从已承诺旧状态出发、不经过当前 finalized tip 的分支，工作量达到当前链工作量再加 `100+144` 个当前 tip 难度的块，任何人可以提交证据永久封存指数。可用分段证明，每段最多 256 头。封存不回滚已付款项，不把 S 改写成另一条链的路径，也没有墙钟超时自动退款。

### 本包额外核对什么，仍不核对什么

| 层面 | 本包行为 | 边界 |
|---|---|---|
| 起始上下文 | 下载自难度周期起点 967680 到确认末端的连续头；认证到固定 anchor；核对 anchor 的 11 个时间戳和 epochStart；重算 `committedAt(969545)` | 不从 Bitcoin 创世重放；967680 的初始难度继承自固定锚点上下文，不能验证其前一个 retarget |
| 正式累加范围 | 969546–972510 完整链接、PoW、难度、MTP、时间上限、整数 U/work | 固定样本的头路径，不是全球选链证明 |
| 前缀 | 全部头的 hash/PoW/链接；有足够 11 个前置时间戳后检查 MTP | 起始 11 个前缀头不具有完整 MTP 上下文 |
| 版本 | 本参考程序要求当前高度的 signed version ≥ 4 | 当前 header-v3 合约没有这一已激活版本下限检查；参考程序通过不能补上链上缺项 |
| 工作量 | 从 anchorWork=0 累加 anchor 后的工作量，并对齐 continuity | 不是从创世累计的 Bitcoin chainwork |
| 时间 | 以固定 EVM 样本块 timestamp + 7200 验证头上限 | 没有逐次重放历史 fold 收据及各次当时的时间条件 |
| 代码 | 固定块运行字节码 SHA-256、参数与绑定一致 | 没有在本包中从 Solidity 编译、审计并证明源到字节码关系 |
| EVM 真实性 | 读链 ID、固定块、finalized、前后块哈希，允许换 RPC 重核 | 依赖所用 RPC；不是自行验证 Ethereum 共识/状态证明 |
| Bitcoin 来源 | 一家公共 HTTP 全量元数据重新编码，并对照固定范围摘要 | 不宣称双来源全量比对或来源运营者独立 |

## 6. 若以后使用资金应用，必须另审的权利

两仪的固定基数公式为 `yangShare=clamp(½+½(S−S0),0,1)`，YIN 取补数；配对毛赔付之和恒为 NOTIONAL。即时份额不是到期前可随时单边兑付的市场报价。

当前永续示例另有自己的规则：两侧以较小本金匹配，多出部分按比例闲置；本金固定、价值在 `[0,2p]` 内；进出场按未来高度定价、申请不可撤销；双方匹配会改变有效敞口，对侧离开后等待指数返回不保证回本。零值账户可被任何人清退，池子缺口可能触发按固定比例永久终止。未入场净本金、退款与已定价退出款分别隔离；“净本金退款”不意味着退还已经收取的入场费。

示例池进出场各收 0.3%，buffer 目标为存续及待入场净本金的 10%，超过目标才向奖励储备归集；这不是每笔再收 10%。当前未来定价与 100 确认导致以小时至天计的等待。5%/10%/25% 是理想匹配下的模型波动档位，不是固定实际年化或收益承诺。旧金库费率与这些账户费率不可混用。

本包不连接这些池、不检查用户仓位、不测试钱包，也不把指数重放通过当作资金应用偿付、可用性或收益验收。公开合约地址的存在不等于主网发布承诺。
